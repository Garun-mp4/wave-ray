# Готовые модели CSI для 1–3 ESP32-S3

Проверено 10 октября 2026 года. Это исследование опубликованных артефактов и
исходного кода, не проверка на подключённом оборудовании.

## Вывод

Среди проверенных проектов не найден готовый кандидат, который подтверждённо
даёт метрические координаты людей, движение и позу на нашей прошивке с 1–3
ESP32-S3 в новой комнате. Поэтому новые веса не подключены к рабочему
распознаванию. Наличие файла весов, красивой демонстрации или низкого training
loss само по себе не подтверждает эти возможности.

## Проверенные кандидаты

| Кандидат | Опубликовано | Почему не включён |
|---|---|---|
| [RuView CSI embedding v2](https://huggingface.co/ruvnet/wifi-densepose-pretrained) | Веса encoder, 8 признаков → 128-мерный embedding; MIT | Это признаки сигнала, не голова координат/позы. Авторы отозвали старое заявление о 100% presence; актуальная triplet-метрика не измеряет точность обнаружения людей. |
| [RuView MM-Fi pose](https://huggingface.co/ruvnet/wifi-densepose-mmfi-pose) | Веса PyTorch, вход 3×114×10, выход 17×2 нормированных координат; CC BY-NC 4.0 | Другой CSI-контракт, 5 GHz benchmark, 2D-поза без метрической локализации. Три ESP32 нельзя считать эквивалентом трёх антенных пар MM-Fi. Авторы отдельно отмечают слабый перенос между комнатами. Некоммерческая лицензия подходит пользователю, но несовместимость входа остаётся. |
| [Wi-Fi Vision](https://github.com/Abinand2631/Wifi-Vision) | Реальный файл `models/tednet_3d_best.pth`, 3 ESP32: 1 TX + 2 RX | Ближайший по числу плат исследовательский кандидат. Не опубликованы достаточные held-out проверки с mean-pose baseline и переносом в новую комнату; не подтверждены S3/наша прошивка, абсолютные метры, несколько людей или животные. Явная лицензия на код/веса при проверке не найдена. |
| [csi-pose](https://github.com/sel00000/csi-pose) | Реальный ESP32-S3 pipeline, сравнение с mean-pose/kNN | Нужны шесть плат: 3 TX + 3 RX. Выход — 2D-поза одного человека; авторы ограничивают доказательства одной сессией/комнатой. Не соответствует 1–3 платам и свободной 3D-локализации. |
| [gavmc/CSI](https://github.com/gavmc/CSI) | Transformer pipeline с четырьмя ESP32-WROOM receivers | Авторы сообщают о leakage в первой оценке, короткой одной сессии и отсутствии надёжной оценки точности. Другой аппаратный контракт. |
| [SWEENEX](https://github.com/ricnah/SWEENEX) | Заявления о готовой 3D-модели | Проверка [загрузчика](https://github.com/ricnah/SWEENEX/blob/main/server/scripts/download_models.py) обнаружила шаблонные ссылки `YOUR_USERNAME`, без SHA-256. В дереве ONNX занимает 1112 байт, external data — 0. Эти файлы не подтверждают заявленные обученные веса и точность. |
| [LoFi](https://github.com/RS2002/LoFi) | Реальные CSI/RSSI ESP32-S3 и координатные метки, 2.4 GHz/52 subcarriers | Полезный набор данных и генератор меток для исследования локализации. Готовая проверенная модель под нашу установку не предоставлена описанным pipeline. Датасет не заменяет обученный детектор. |
| [Espressif ESP-CSI](https://github.com/espressif/esp-csi) | Официальные сбор CSI, motion/presence и on-site training | Практичная база физического сбора сигнала; не готовая многоклассовая 3D-модель людей/животных. |

Утверждения о качестве перечисленных моделей — **CLAIMED** авторами, не наши

`5dacdc9683d9cd233ee1933480ad42d002b46583`: [обучение](https://github.com/Abinand2631/Wifi-Vision/blob/5dacdc9683d9cd233ee1933480ad42d002b46583/train.py),

Не исполнялись чужие Python-скрипты и pickle checkpoints.

## Что включено в приложение

- Go принимает реальные аппаратные потоки; `auto` ожидает вход без генератора.
  Запуск с `simulate`/`simulated` отклоняется.
- Браузер не генерирует кадры при сбое, игнорирует старый demo preference и
  отвергает синтетические кадры REST/WS.
- Исследовательский `pose_v1` отключён в Compose по умолчанию. Его
  normalized-image output не становится измеренной позицией в пространстве.
- Space показывает только операторскую расстановку устройств, состояние
  приёма CSI и отсутствие доступной локализации объектов.
- Не отображаются придуманные скелеты, животные, радиусы покрытия, этажи и
  позиции из RSSI/hotspot. Отсутствие результата означает «недоступно», не
  «в комнате нет людей».

## Условия для безопасного подключения будущей модели

1. Опубликованные веса, лицензия, immutable revision и SHA-256.
2. Точный контракт аппаратуры: передатчик/приёмники, ID, антенны, частота,
   полоса, индексы поднесущих, sampling rate, синхронизация и нормализация.
3. Известная система выходных координат; camera-relative skeleton не выдаётся
   за координаты относительно роутера или положение на другом этаже.
4. Пустая комната и отрицательные примеры, раздельные сессии для train/test,
   отсутствие перекрытия временных окон, mean-pose baseline для pose PCK.
5. Проверка на нашей прошивке и реальных записях с независимым ground truth.
   Отдельные проверки количества людей, животных и движения, если заявляются.
6. Измеренная задержка всего пути CSI → inference → API → браузер, поведение
   при потере устройства/пакетов и отказ от вывода при непригодном входе.

Без оборудования можно проверить ПО и защиту от ложных результатов; качество
реального обнаружения и задержку RF-инференса сейчас измерить нельзя.
